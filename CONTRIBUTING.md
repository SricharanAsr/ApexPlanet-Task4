# Contributing to ApexPlanet - Task 4

Thank you for your interest in contributing to our Data Analytics project! We welcome contributions that improve the quality of our analysis, documentation, and tools.

## How to Contribute

1.  **Fork the Repository**: Create a personal copy of the project.
2.  **Create a Branch**: Use a descriptive name for your branch (e.g., `feature/add-new-test`).
3.  **Make Changes**: Ensure your code follows the established style and includes tests.
4.  **Run Tests**: Verify your changes by running `pytest`.
5.  **Submit a Pull Request**: Provide a clear description of your changes and why they are necessary.

## Coding Standards

-   **Python**: Follow PEP 8 guidelines.
6.  **Documentation**: Use Google-style docstrings for all new functions and classes.
7.  **Testing**: All new features must include unit tests.

## Bug Reports

If you discover a bug, please open an issue with the following details:
-   A clear description of the problem.
8.  Steps to reproduce the bug.
9.  Expected vs. actual behavior.
