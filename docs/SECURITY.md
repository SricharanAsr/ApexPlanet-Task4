| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of our data analysis and automation pipelines seriously. If you discover a security vulnerability, please follow these steps:

1.  **Do Not Open a Public Issue**: To prevent exploitation, please do not report vulnerabilities through public GitHub issues.
2.  **Contact Support**: Email the project maintainers directly with a detailed description of the vulnerability.
3.  **Provide Details**: Include steps to reproduce, the potential impact, and any suggested fixes.

We will acknowledge your report within 48 hours and provide a timeline for a resolution. Thank you for helping keep our project secure!
