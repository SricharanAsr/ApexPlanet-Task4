## Overview
This repository contains the complete deliverables for Task 4 of the ApexPlanet Data Analytics project. The goal was to synthesize multi-phase analysis into a cohesive business narrative and validate key findings using rigorous statistical methods.

## Contents

### 1. Statistical Validation
- **[statistical_test.py](statistical_test.py)**: Python script performing Welch's T-test on Average Order Value (AOV) across demographics.
- **[hypothesis_testing_report.md](hypothesis_testing_report.md)**: Detailed report confirming that the 35-44 age group has a statistically significant higher AOV ($443.12) compared to the 25-34 group ($339.19).

### 2. Business Narrative
- **[data_story.md](data_story.md)**: A structured storytelling document covering data wrangling, market analysis, and the final call to action.

### 3. Stakeholder Deliverables
- **[final_presentation.html](final_presentation.html)**: A premium, interactive HTML/CSS presentation deck for executive stakeholders.
- **[presentation_script.md](presentation_script.md)**: A professionally drafted 7-10 minute presentation script for LinkedIn or executive briefings.

## Key Insights
*   **Electronics Dominance**: Revenue is primarily driven by high-ticket Electronics items ($104K+).
*   **Segment Muscle**: The 35-44 age segment provides the highest immediate value.
*   **Stable Loyalty**: Customer retention stabilizes at a healthy 30-50% after the third month.
